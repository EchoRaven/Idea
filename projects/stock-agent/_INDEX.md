## ⚠️ 需要你注意的

### 1. M8 机制已通电并测过，但学习效果检验本身有一个未被点名的混杂

**进展是真实的**：`replay_loop.py` 在隔离库里跑通了完整 `run_trade_cycle`（含撮合/平仓/复盘），
25 天历史重放产出 2 笔平仓往返 → 2 条 `trade_review` 写进记忆。这解决了上一版索引里
「记忆系统建好了但没通电」的问题——**通电本身是确凿的**。

**但学习效果的答案不乐观**：`learning_ab.py` 用 difference-in-differences 比较「有复盘的
AMD/JPM」vs「无复盘的 AAPL/MSFT」，结果 **DiD≈0**——委员会读到自己那笔具体的亏损复盘后，
行为几乎不额外改变。文档自己也诚实标注「样本极小，机制探针非结论」。

**我要补充的一点，文档里没有明确点名**：这次 DiD 的 treatment/control 分组**完全按标的划分**
（有记忆的正好是 AMD/JPM，没记忆的正好是 AAPL/MSFT），不是随机分配。这意味着 DiD≈0
既可能说明「委员会真的没权衡复盘」，也可能只是「AMD/JPM 和 AAPL/MSFT 本来对委员会来说
行为就不一样」——两种解释目前无法互相排除。在下一轮扩样本时，最好让「有没有复盘」独立于
标的本身变化（比如同一标的在不同回放窗口里分别有/没有复盘），而不是靠标的选择自然形成分组。

### 2. 置信度→收益不显著：证据强度升级了，但仍是负面结果，且它还在支撑大片 UI

PROGRESS §2.4 这次把结论口径从「样本不足看不出」正式升级为「**测了，现有证据里置信度不
预测收益**」——三区间干净重跑、39 条买入 / 22 个决策日，首次跨过显著性检验需要的样本量门槛。
这是诚实的进步：证据强度变强了，但结论本身没变好。

如果这个不显著在未来更大样本下依然成立，`confidence` 这个字段目前撑着记分卡的分桶展示、
前瞻收益 UI 等一整套呈现——需要提前想一下：万一置信度始终不能预测收益，这些界面要不要改口径
（比如降级为"仅供参考"而非当前"看起来像信号"的呈现方式）。这不是要现在就改，是提醒这条依赖链
的下游影响面比较大。

### 3. Finding A：安全红线 #2 靠下游兜，不在函数内强制（未变）

`submit_decision` 信任调用方传入的 shares，字面红线「股数永远服务端算」没有在函数内强制，
靠闸门拒绝超限买 + 撮合 `min(order, held)` 封顶卖出来遏制。处理方式合理（回归测试钉死遏制性、
暂缓重构），但仍是安全模型里唯一依赖纵深防御而非局部不变量的地方，建议在函数体上方补一行注释
指向 Finding A 和对应回归测试，方便下一个改动闸门/撮合逻辑的人看见这根线。

### 4. 文档的自我校准习惯延续到了这一批

新增的 §2.6「证据强度总声明」把「单一行情区间、基本面回放带未来函数、universe 有幸存者偏差」
这些局限主动摊开写明；§2.4 的口径升级（样本不足→测了不显著）也是同一种纪律的体现。这不是要修的
问题，是要保持的习惯——上一版索引夸过一次，这次继续成立。

### 5. 三个项目独立收敛到同一条方法论：小样本 + 非随机分组最容易骗过自己

- stock-agent：本次新发现的 DiD 分组按标的划分、非随机，可能与 memory 状态混杂（见上第 1 条）；
  历史上还有「按行数而非独立观测数算显著性」的自捉坑。
- avo-redteam：核心杠杆数字 Δ+1.00 / Δ−0.67 / 0/5 全部来自 reps=3，无区间估计。
- [capsec-strain-invariance](../capsec-strain-invariance/_INDEX.md)：给 diversion 比值配上
  Wilson 95% CI 后发现 n_adm=1–3 的区间几乎覆盖 [0,1]，是三个项目里第一次把「小样本结论不可信」
  真的算成了区间。

**可迁移的具体建议**：`learning_ab.py` 的 DiD 设计如果要站得住，可以参考 capsec 那套做法——
不只报 DiD 点估计，配一个自助法（bootstrap）或至少标注清楚"这是 n=2 的机制探针，不是可信区间"，
和现有措辞一致但更显眼；同时把"treatment 按标的划分"这个混杂显式写进方法局限里，而不是只留在
"样本极小"这句笼统的话里。

## 关键决策记录

- **两级漏斗**：不对全池调 LLM（成本不可控），确定性筛选器粗筛，LLM 只做细活。
- **建议与授权分离**：LLM 输出全部经 clamp，是否下单、下多少股由服务端在 LLM 之外决定。
  委员会草案里**根本没有 shares 字段**。
- **`as_of` 与价格一律服务端派生**，payload 无通道 —— 防伪造未来日期绕过熔断/冷却。
- **测量先于优化**：改策略前先能量出改动效果，避免拿单一行情过拟合。
- **跨区间才算数**：任何「某类决策好/坏」的结论至少跨一个反向行情区间验证。
  这条规则直接救回了「卖出反预测」的误判（见 PROGRESS §2.3）。
- **诚实优先**：宁可报「样本不足/不显著」，不把弱证据包装成结论。
- **Finding A 暂缓重构**：contained 的字面偏差优先用「钉不变量」守，而非改契约。
- **口径升级的具体做法（新增，2026-08-04）**：置信度→收益的结论从「样本不足无法判断」升级为
  「测了，现有证据下不显著」，靠的是把评测样本扩到三区间（牛/熊/震荡）、覆盖 22 个独立决策日
  后再重新跑显著性检验——"升级结论口径"不是换个说法，而是先把样本量做够。
- **用 DiD 而非胜率/相关系数测"学习有没有用"（新增，2026-08-04）**：M8 判断委员会是否权衡自己的
  复盘，用的是 with-memory vs without-memory 的 difference-in-differences，而不是简单看有记忆
  那组的胜率——但当前这版分组按标的划分、非随机，是明确记录在案的方法局限（见上「需要你注意的」第 1 条）。
