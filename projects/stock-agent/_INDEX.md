### 1.（本轮最重要，新发现）新文档 EVALUATION.md 与同批 PROGRESS.md/ROADMAP.md 对 M9 attempt#2 的进度描述直接矛盾

`EVALUATION.md` §5「到目前为止的结论」第四条写:

> **M9 attempt#2**(把该票上次结果显眼摆出)plumbing 已就绪、可测,**尚未验证也未接线上**
> (待跑 `--prominent` A/B)。

但同一批到达的 `PROGRESS.md` §2.5 和 `ROADMAP.md` M9 一节都明确报告 attempt#2 **已经跑完**,
给出具体 Wilson 95% CI 数字:treatment WITH 0.81 [0.65,0.91] vs WITHOUT 0.53 [0.36,0.69],
结论是**不仅无效、还适得其反**(显眼提醒亏损反而让委员会买得更多,疑似报复/抄底心理),
**已否决,绝不接线上**。

三份文档同一批交上来,对同一件事却给出两种完全相反的进度描述——一个说"还没跑",两个说
"跑完了、已经否决"。大概率是 `EVALUATION.md` 起草时引用了旧版 `PROGRESS.md` 的措辞,写完
后 `PROGRESS.md`/`ROADMAP.md` 各自更新了 attempt#2 的结果,而 `EVALUATION.md` 没跟上。
不影响项目本身的进展(结果本身是清楚且一致的,只是 EVALUATION 这一份文档滞后),但下一个
只读 `EVALUATION.md` 的人会得到过时信息。建议下次更新时把 EVALUATION §5 第四条改成与
PROGRESS/ROADMAP 一致的"已验证、已否决"表述,并补上 Wilson CI 数字。

### 3.（重要,来自本轮新内容)M9 attempt#2 backfire 本身是一次高价值的负面结果,评测纪律确实拦下了一个"看似正确、实测有害"的改动

给委员会"该票上次亏了多少钱"这种直觉上显然正确的提醒,实测让它**更敢买**而不是更谨慎——
这是一次典型的"面上正确、上线会造成危害"的改动被测量拦下的案例,证明这套 `learning_ab.py`
+ Wilson CI 的方法论本身在真实起作用,不是摆设。但代价是:M9 目前两次朴素 prompt 干预
(强化 memory 段 / 显眼摆顶部)都失败了,`ROADMAP.md` 给出的下一步方向——**结构化约束**
(如 bear 角色强制引用该票近端已实现盈亏并质询、或做成独立的量化盈亏字段)——目前完全
没有实现或验证过,是 M9 唯一具体可执行的下一步。

### 4.（新发现)M10 换模型探索:核心验证结果本批文档明确写着"进行中"但未交付

`PROGRESS.md` §2.7 和 `ROADMAP.md` M10 都只给出了**负面/中性**的阶段性证据——gpt-5.5
定性更强(会引用亏损、会说"不为反弹重复买入"),但套用为补偿 Gemini 设计的默认校准后
**买入率仅 2%**(~98% hold,过度保守)。真正决定 M10 能不能往下走的"relaxed 校准 + gpt-5.5

这条线是卡住了还是真的在推进。

### 5.（延续,原有发现,本轮无新证据)DiD 的 treatment/control 仍按标的划分、非随机分组

`learning_ab.py` 的 with/without-memory 对比,治疗组正好是有复盘的 AMD/JPM、对照组正好是
无复盘的 AAPL/MSFT,不是随机分配——DiD≈0(以及 attempt#1/#2 的区间估计)既可能说明"委员会
真的没权衡复盘",也可能混着"这两组标的本来行为就不同"。本轮 attempt#2 的显眼摆放实验换成
了同一批标的重新测,同样的分组混杂原样存在,文档本身仍只在"样本极小"这句话里带过,没有单独
点名这一条。

### 6.（延续,无新进展)置信度→收益不显著,且现在和 M10 换模型探索交织在一起

`PROGRESS.md` §2.4 的结论(置信度不预测收益)本轮没有新证据,但现在有了一个新变量:如果
gpt-5.5 + relaxed 校准最终证实置信度**能**预测收益(§2.7 提到这是重验要看的问题之一),

## 关键决策记录

- **两级漏斗**：不对全池调 LLM（成本不可控），确定性筛选器粗筛，LLM 只做细活。
- **建议与授权分离**：LLM 输出全部经 clamp，是否下单、下多少股由服务端在 LLM 之外决定。
  委员会草案里**根本没有 shares 字段**。
- **`as_of` 与价格一律服务端派生**，payload 无通道 —— 防伪造未来日期绕过熔断/冷却。
- **测量先于优化**：改策略前先能量出改动效果，避免拿单一行情过拟合。
- **跨区间才算数**：任何「某类决策好/坏」的结论至少跨一个反向行情区间验证。
  这条规则直接救回了「卖出反预测」的误判（见 PROGRESS §2.3）。
- **诚实优先**：宁可报「样本不足/不显著」，不把弱证据包装成结论。
- **Finding A 暂缓重构**：contained 的字面偏差优先用「钉不变量」守，而非改契约。
- **口径升级的具体做法（2026-08-04）**：置信度→收益的结论从「样本不足无法判断」升级为
  「测了，现有证据下不显著」，靠的是把评测样本扩到三区间（牛/熊/震荡）、覆盖 22 个独立决策日
  后再重新跑显著性检验——"升级结论口径"不是换个说法，而是先把样本量做够。
- **用 DiD 而非胜率/相关系数测"学习有没有用"（2026-08-04）**：M8 判断委员会是否权衡自己的
  复盘，用的是 with-memory vs without-memory 的 difference-in-differences，而不是简单看有记忆
  那组的胜率——但当前这版分组按标的划分、非随机，是明确记录在案的方法局限（见「需要你注意的」#5）。
- **朴素的"提醒亏损"干预已被证伪，需要结构化约束（新增，2026-08-05）**：M9 把该票上次亏损结果
  显眼摆在 prompt 顶部，实测让委员会买得更多而非更谨慎（疑似报复/抄底心理），已用 Wilson CI
  证实区间分离，据此否决、不接线上。下一步方向改为结构化约束（如 bear 角色强制引用该票已实现
  盈亏并质询）而非情绪化提醒文字。
- **模型与 prompt 强耦合，换模型前必须重新校准（新增，2026-08-05）**：gpt-5.5 套用为补偿 Gemini
  乱买设计的默认校准后 ~98% hold（几乎不下单），说明"委员会决策校准"不是独立于模型的通用设置。
  换模型必须配套重新调校准（已加 env 门控的 relaxed 校准应对，重验进行中）。
- **评测方法论应该有专门文档承载（新增，2026-08-05）**：`EVALUATION.md` 把散落在 PROGRESS/ROADMAP
  里的评测纪律独立成篇，是好的文档结构决策——但也因此暴露了一个新问题：独立文档如果不和其它
  文档同步更新，会成为矛盾的来源（见「需要你注意的」#1）。多文档并行时，内容一旦变化需要
  同步检查所有引用它的地方，不能只改一处。
